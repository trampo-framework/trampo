# people/

One file per person, `people/<name>.md`, for preferences that are theirs alone: tone, report shape, pacing, words to
avoid. The layers are core rules, then the team's instructions and memory, then a personal file. A preference changes
how a step runs for its owner, never whether it runs: it cannot skip a gate, a test or an approval. A rule for the
whole team goes in `memory/`, even when one person said it first.
